# C1 统计有效性与置信区间

## 主实验样本量

主验证每个 payload、method 有 50 个 packet；169 与 507 的 Base/Fixed/Proposed/Oracle/Perfect 采用配对随机场景。正式报告的 hash pairing 100/100 通过，因此方法差值可以使用配对 bootstrap。

## Proposed 相对 Fixed 的 bootstrap 结果

| Payload | 指标 | 差值 Proposed-Fixed | 95% CI |
|---|---|---:|---:|
| 169 | NMSE | -0.00261055 | [-0.00309662, -0.00220486] |
| 169 | Pre-LDPC BER | -0.00166574 | [-0.00241390, -0.00093209] |
| 507 | NMSE | -0.00273992 | [-0.00320783, -0.00233373] |
| 507 | Pre-LDPC BER | -0.00148776 | [-0.00257371, -0.00037033] |
| 169 | Goodput | 正向 | [0, 6.70343] |
| 507 | Goodput | 正向 | 约 [-1.4e-16, 3.51132] |

因此 Proposed 相对 Fixed 的 NMSE 和 Pre-LDPC BER 改善有稳定统计支持；Goodput 的 95% 区间包含 0，不能写成已证明的显著吞吐提升。

## Codeword pass 的 Wilson 95% 区间

| Payload | Method | 成功数/总数 | 比例 | Wilson 95% CI |
|---|---|---:|---:|---:|
| 169 | Base | 23/50 | .460 | [.330,.596] |
| 169 | Fixed | 31/50 | .620 | [.482,.741] |
| 169 | Proposed | 34/50 | .680 | [.542,.792] |
| 169 | Perfect | 45/50 | .900 | [.786,.957] |
| 507 | Base | 78/150 | .520 | [.441,.598] |
| 507 | Fixed | 113/150 | .753 | [.679,.815] |
| 507 | Proposed | 118/150 | .787 | [.714,.845] |
| 507 | Perfect | 132/150 | .880 | [.818,.923] |

507 的总数是 150，因为三个 50 包场景组成了该汇总口径；正文需说明分母，避免读者误解为 50。

## 统计限制

50 包足以做工程级 paired bootstrap，但不足以支持很细的 BLER 曲线、低概率错误尾部或普适性结论。已有 SNR localization 报告记录了 raw BLER 非单调告警，尤其不能在未修复 LLR/decoder 诊断前做 SNR 门限插值。

## 建议写法

建议报告均值、配对差值、95% bootstrap CI、样本数和随机种子；把 codeword pass 写成描述性结果或给出 Wilson 区间；把 Goodput 改为有效数据吞吐率并明确未计入前导开销。
